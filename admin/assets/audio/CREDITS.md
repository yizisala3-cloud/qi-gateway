# 铃声资产来源与许可（规划管理一期）

本目录音频仅用于浏览器内提醒（闹钟 / 计时器），全部为 CC0（公有领域）许可，可自由使用、修改与分发，无需署名；以下信息按来源页面登记备查。

## alarm-clock.mp3 — 闹钟铃声

- 曲名：Calm Piano 1 (Vaporware)
- 作者：The Cynic Project
- 来源页面：https://opengameart.org/content/calm-piano-1-vaporware
- 文件直链：https://opengameart.org/sites/default/files/003_Vaporware_2.mp3
- 许可：CC0 1.0 Universal（Public Domain Dedication）
- 用途：待办开始/结束闹钟到点响铃；页面打开期间循环播放，直到 user 点掉。

## timer-done.ogg — 计时器结束音

- 曲名：Slow Piano Intermission
- 作者：Julie Damsgaard / Spring
- 来源页面：https://opengameart.org/content/slow-piano-intermission
- 文件直链：https://opengameart.org/sites/default/files/slow%20piano%20intermission_0.ogg
- 许可：CC0 1.0 Universal（Public Domain Dedication）
- 用途：计时器倒计时结束，播一次即停。
- 兼容性备注（来自需求约定）：若目标浏览器不支持 ogg（如 iOS Safari），可改用闹钟曲另一段并保持 MP3 格式。

## 引用方式

页面内通过 `/admin/assets/audio/...` 部署内路径引用，禁止任何本机绝对路径。
