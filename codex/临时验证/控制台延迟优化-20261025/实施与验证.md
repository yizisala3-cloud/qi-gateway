# 控制台常用操作延迟优化

本轮完成本地实现与验证，尚未部署，也未执行生产迁移或生产业务写操作。

## 已实现

| 范围 | 变化 |
| --- | --- |
| 开始、部分完成、完成待办 | 新增原子命令，一次数据库 RPC 完成；轮次基准、目标计数触发器、重算登记共同提交。操作身份支持响应丢失后重试，原内容保留供核实 |
| 保存后的界面 | 根据服务端回执更新实例、任务和排程，随后后台校准；保留失败提示与刷新重试。旧轮询、旧页面回执不能覆盖新事实和编辑草稿 |
| 新建与恢复刷新 | 复用同步排程的结果更新界面；创建身份与删除登记合并读取，保留幂等、首次排程、删除后不复建的规则 |
| 规划看板及全部待办 | 看板的两份实例读取和重算状态并行；全部待办复用已筛选的任务数据，减少重复查询 |
| 配置 | 先显示卡片框架，各卡片独立就绪；后到响应不重建已可操作卡片，不清除输入或密钥会话 |
| 记忆总结及日志 | 独立状态并行加载；日志元数据和列表使用同一冻结时间范围，并保留卸载、筛选代次保护 |
| 记忆列表及保存后刷新 | 一次请求返回卡片字段、正文摘要和准确总数；详情仍读取完整内容。保存后的列表和详情同时刷新 |
| 入口资源与状态 | 备忘录和长期目标按首次切入加载；复用刚完成的鉴权检查更新在线状态；同步前端资源版本 |

## 量化复核

50 条每日待办的合成场景，以下是数据库网络往返数，不是生产耗时：

| 操作 | 原来 | 现在 |
| --- | ---: | ---: |
| 完成（普通任务／按完成时间间隔排程） | 6／8 | 1 |
| 开始／部分完成 | 4／4 | 1／1 |
| 新建（携带操作身份） | 11 | 10 |
| 全部待办实例列表 | 3 | 2 |
| 当前看板 | 5 次串行 | 5 次，其中 3 份独立读取并行 |

默认规划入口静态依赖从 18 个模块、407,330 字节，减少到 16 个模块、294,571 字节，减少 112,759 字节。这里统计未压缩源码，不代表浏览器实际传输体积。

证据见 `调用数量复核.json`、`静态依赖对比.json`。尚未上线，本轮不报告线上点击秒数、浏览器 FCP/LCP 或 P95。

## 验证

- 最终常规回归：1,925 项通过，1,257 个子用例通过；数据库套件在常规回归中按原有开关跳过。
- 新增真实 PostgreSQL 命令验证：7 项通过，4 个子用例通过。覆盖单次 RPC、并发重放、身份冲突、中空轮次、时间来源与分钟舍入、重算开关、权限和失败整体回滚。
- 已执行包含数据库的完整相关回归，2,273 项及 1,384 个子用例通过；唯一剩余项为前端源码断言仍匹配旧按钮写法，已同步，并在上述最终常规回归中通过。数据库业务测试和完整迁移链重放已通过。
- 新增前端行为验证覆盖卡片独立加载、输入节点保留、并行读取、旧页面响应隔离、回执先显示而校准仍在等待、旧轮询拒绝、未知结果原身份重试。
- `git diff --check` 通过；原有用户改动已保留，共享组件仅同步资源版本。

Windows 本地测试设置 `PYTHONUTF8=1`；真实数据库测试另设置 `PGTZ=Asia/Shanghai`，与既有套件的时间字符串断言一致。未修改网关生产时区。
