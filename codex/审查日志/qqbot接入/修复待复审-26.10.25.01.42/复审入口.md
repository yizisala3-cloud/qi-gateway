## 需要核对的不变量

当前实例持续持有效租约且没有实际本地模型任务时，遗留in_flight必须在后续普通租约周期收敛，不能依赖pending是否为True。旧结果隔离与当前账本恢复是两个独立义务。

| 持权检查时的状态 | 必须执行的行为 |
| --- | --- |
| 其它owner仍有有效租约 | 不写评估／调度记录 |
| 本地模型实际活跃 | 保留同一attempt，等它完成 |
| 同attempt的已知结果待提交 | 当前时间核权，以原完成时刻结算真实分类 |
| 旧结果stale，新账本仍在途 | 丢旧结果但保留独立检查；本轮返回，下次普通持权周期处理当前记录 |
| 没有已知结果的遗留在途 | 当前权威owner按未知中断或revision失效取消处理 |
| 已经结算 | 重复续期不重复计故障／代次／日志 |

业务改动仅`gateway/qqbot.py`：合法持权续期无条件进入原收敛入口；deferred重放和正常finish的stale都不清除独立义务。无SQL、前端、环境变量、发送频率、AI每日额度或新后台循环变化。
